# Sources and claim mapping

**Research cut-off:** November 16, 2026. These links were reviewed for project preparation. Cite them on-screen when discussing numbers and include the source name in your voiceover where natural.

## [S1] GitHub product announcement (primary source)

GitHub. (2026, June 17). *GitHub Copilot app generally available*. GitHub Changelog.  
https://github.blog/changelog/2026-06-17-github-copilot-app-generally-available/

**Supports:** General availability on macOS, Windows and Linux; starting agent sessions from issues, PRs and prompts; parallel sessions on separate branches/worktrees; developer diff review, validation and pull requests.  
**Caution:** Product announcement documents a capability and vendor claim; it does not demonstrate that every developer uses or benefits from the features.

## [S2] JetBrains developer survey (original source)

Bogdanov, M. (2026, August). *AI Coding Agents: Adoption Trends*. JetBrains Research, based on the Developer Ecosystem Survey 2026.  
https://blog.jetbrains.com/research/2026/08/ai-coding-agent-adoption-2026/

**Supports:** Survey of more than 15,000 professional developers. Among respondents in May–July 2026, 90% used local or remote AI coding agents at work at least weekly and 68% daily. Also describes leading tools and sampling/weighting methodology.  
**Caution:** Do not say 90% of *all* software developers worldwide use an agent. Use 'surveyed professional developers' and specify dates. Self-reported tool use does not measure reliability or productivity.

## [S3] NBER empirical research (working paper)

Demirer, M., Musolff, L., & Yang, L. (2026, May; revised September). *Writing Code vs. Shipping Code: Productivity Effects Across Generations of AI Coding Tools*. NBER Working Paper No. 35275.  
https://www.nber.org/papers/w35275  
DOI: https://doi.org/10.3386/w35275

**Supports:** Matched event-study analysis using more than 500,000 GitHub developers and AI usage telemetry. In the paper, cumulative effects for autonomous coding agents are +240% commits, +80% projects and +30% releases; large increases in coding activity attenuate by final output.  
**Caution:** These are paper-specific estimated cumulative effects and not universal speedups, raw before/after counts, proof of causality in every workplace, or a prediction about employment. Working paper may be revised.

## [S4] Peer-reviewed adoption study (optional supporting evidence)

*Agentic Much? Adoption of Coding Agents on GitHub*. (2026, June 26 online). *ACM Transactions on Software Engineering and Methodology*.  
https://doi.org/10.1145/3822180

**Supports:** Study of 128,018 GitHub projects, reporting an estimated coding-agent adoption rate of 22.20%–28.66% as of February 21, 2026, using repository traces.  
**Caution:** Its project-based inferred adoption rate is a **different population and definition** from JetBrains' developer survey. Do not compare the two figures as if they measured the same thing.
