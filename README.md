## Project summary

**Research question:** How are AI coding agents changing software development workflows in 2026, and which skills remain important for programmers?

AI coding agents go beyond suggesting individual lines of code. Given a programming task, they can inspect a codebase, make multi-file edits, run tests and propose changes for developer review. Three 2026 developments frame our investigation:

1. **June 17, 2026:** GitHub announced general availability of its Copilot desktop app, featuring agent-driven development sessions, separate branches/worktrees, testing and pull-request review [S1].
2. **May–July 2026 survey, reported in August:** JetBrains reported **90% weekly** and **68% daily** use of AI coding agents among surveyed professional developers [S2]. This is a survey result, not a census of all programmers.
3. **May 2026 research, revised September:** An NBER study tracking over 500,000 GitHub developers found much larger effects on coding activity than on software releases [S3]. This does not prove agents replace developers.

**Main conclusion:** AI agents can accelerate writing and modifying code, while problem definition, debugging, testing, security and accountability still require software engineering judgment.

## Key findings

- Coding agents are increasingly incorporated into GitHub-centered software workflows [S1, S2].
- Adoption data measures use, **not necessarily effectiveness or code quality** [S2].
- NBER reports cumulative effects associated with autonomous agent adoption of **+240% commits, +80% projects, and +30% releases** in its study design. Activity and shipped products are different measurements; the percentages must not be presented as a universal productivity guarantee [S3].
- A representative development workflow is **specify → agent edits → run tests → inspect diff → human approval**. Our local Python demo examines why tests matter.
